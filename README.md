# Convite Toral 32

Convite animado de aniversario. Pagina unica, sem build e sem dependencias.

## Arquivos

- `index.html` : a pagina inteira (HTML, CSS e JS no mesmo arquivo)
- `toral.jpg` : a foto da capa

Os dois precisam ficar na mesma pasta.

## Publicar no GitHub Pages

1. Crie um repositorio novo no GitHub. Publico funciona direto; privado exige conta Pro para usar Pages.
2. Suba `index.html` e `toral.jpg` na raiz do repositorio.
3. No repositorio, va em Settings > Pages.
4. Em Source, escolha "Deploy from a branch", selecione a branch `main` e a pasta `/ (root)`. Salve.
5. Em um ou dois minutos o link aparece no topo dessa mesma tela, no formato https://SEUUSUARIO.github.io/NOMEDOREPO/
